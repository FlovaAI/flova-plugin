# Flova Creative Debrief

Connect actual performance to creative choices and a testable next production decision. Reuse the user's goals, tracker and prior analysis. General cleaning, joins, statistics, plots and data-quality checks belong to the host's existing analysis tools; possessing those tools does not grant platform-account access.

## Contents

- [Creative tracker](#creative-tracker): connect each produced version to publication and results.
- [Analysis and interpretation](#analysis-and-interpretation): compare within actual data limits.
- [Next production brief](#next-production-brief): turn evidence into what to keep, change or test.

## Creative tracker

Create the tracker during production, add real publication/upload IDs when returned, and update conclusions after review. It is an output table to create or continue, not an input document the user must find. Use the user's existing table, or UTF-8 `docs/creative-tracker.csv`; no pre-existing `creative-tracker.md` specification is required.

| Fields | Record |
|---|---|
| Creative ID, batch, file | Stable creative identity, iteration and actual export |
| Production source, parent/version, previous review | Script/storyboard, used materials, changed version and test lineage |
| Product/topic, angle | Audience, situation and reason to buy/watch |
| Hook type and first line/frame | Agreed batch vocabulary plus the actual opening |
| Format, presenter, duration, ratio | Observable creative choices |
| Hypothesis and control | What changed, what stayed fixed, what to observe |
| Platform/placement, post/ad/material IDs and links | Actual publication and many-to-many mappings |
| Publication time, state, latest conclusion | Lifecycle and the latest evidence-backed assessment |

Agree the batch's labels before production. Use new rows for new versions and mark replaced versions; do not overwrite history. Multiple platform publications of one creative retain a shared creative ID and separate platform IDs. Keep multiple-ad mappings rather than silently double-counting creative results.

When useful for platform reporting, use the same short name for the exported file, uploaded material and suggested ad name:

```text
<product>_<angle>_<hook>_<format>_<ratio>_<batch>
serum_dry-skin_pain_ugc_916_R2
```

Retain an established user convention. Store each review's metrics separately, for example `results-<date>.csv`, linked by creative ID. Populate real file and resource IDs only when they exist.

## Analysis and interpretation

Start with the actual decision and objective. An opening test may use early retention, completion and clicks; sales decisions still need the agreed conversion/return measures. High retention alone is not a sales win.

Read authorized platform data through the available connection, or use a supplied/chosen export. Follow the selected inspiration's connection checks before declaring a connection unavailable. Do not ask for an export solely because one plugin search returned no result.

For historical creatives without a tracker, observe the content and tag angle, actual opening, proof, format and version changes before looking at performance. Mark these as retrospective labels. If video cannot be obtained, distinguish observed copy/name from unverified visual labels. Reuse relevant Teardown analysis when available; a fresh full HTML report is not required for every review.

Give the host analysis tools the actual comparison scope: objective/event, complete dates and attribution maturity, audience and placement, time zone, currency, attribution window, dynamic combinations, and sample/exposure limits. Compare platforms separately before combining directional signals.

Keep observed data, explanations and next hypotheses distinct. Unequal spend or exposure makes historical comparison non-random; low-spend creatives are not automatically losers. Recent conversions may still arrive. A combined ad's performance does not isolate one constituent element's causal effect. Suspected fatigue needs a trend and checks for changed audience, delivery, bid, budget or conversion conditions.

Use business signals as questions: strong opening with later drop-off may warrant checking promise/body alignment; strong clicks with weak conversion may point to the offer or landing experience; repeated comment objections may suggest a grounded demonstration. None automatically proves a cause or requires new generation. When evidence is insufficient, specify the next comparison rather than inventing a winner.

## Next production brief

Deliver the review scope, identified creatives, evidence, hypotheses and a concrete handoff:

- **Keep:** the angle, shot, person, sound or master that remains, with its actual location/ID.
- **Change:** the exact opening, proof, text or ending to replace, and what stays unchanged.
- **Test:** the business hypothesis, control, single intended variable and observable result. Record all changes when more than one variable changed.
- **Production:** destination workflow, needed facts/references, quantity and specs.

Reuse a viable body and ending for a hook-only revision. Link the next batch to its parent and prior review. If the user only requested analysis, stop at the analysis/brief. This skill does not create ads, change budgets or targeting, publish, or authorize spending; those actions need their applicable workflow and the user's authorization.

Missing a fixed helper name is not itself a blocker when the inspiration supplies sufficient rules. Identify actual data, computation or access gaps; do not substitute a qualitative guess for a statistical result.
